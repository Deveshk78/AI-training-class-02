# Chapter 4 Cheat Sheet

## Core idea
A multimodal system handles more than text by routing work across multiple content types.

## Common Java design
- adapters for each media type
- orchestrator for reasoning
- preprocessing pipeline
- model provider abstraction

## Interview answer template
> “In Java, I would model multimodal AI as separate adapters for image, audio, and video, unified behind a common orchestration service. This keeps each modality modular while preserving a consistent architecture.”
