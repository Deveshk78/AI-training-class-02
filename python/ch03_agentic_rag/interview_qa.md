# Chapter 3 Interview Q&A

## 1. What is agentic RAG?
Agentic RAG adds planning, tool use, and iterative reasoning to retrieval-based systems.

## 2. Why do we need a planner?
A planner decides when to retrieve, when to call a tool, and when to stop. This is essential for multi-step or dynamic queries.

## 3. What is the difference between tool use and retrieval?
Retrieval finds relevant context inside a knowledge base. Tools fetch external or dynamic information such as calendars, systems, or APIs.

## 4. Why is iteration important?
Some questions require several steps, such as retrieving evidence, checking a tool, and then synthesizing a final answer.

## 5. How do you explain MCP briefly?
MCP standardizes how tools are exposed to agents so they can be reused across tasks and environments.
